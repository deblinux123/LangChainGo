# Chapter 09: There Is and There Are

## 1. Learning Objectives

By the end of this chapter, you will be able to:

- Use there is and there are to describe the existence of people and things.
- Make positive, negative, and question forms.
- Use a, an, some, and any with there is and there are.
- Describe places, rooms, and everyday situations.
- Use there is and there are with countable and uncountable nouns.

## 2. What Do There Is and There Are Mean?

We use **there is** and **there are** to say that something or someone exists or is present in a place.

Examples:

- There is a book on the table.
- There are three students in the classroom.
- There is some milk in the refrigerator.
- There are two parks near my house.

The choice depends on the noun:

- There is + singular countable noun or uncountable noun.
- There are + plural countable noun.

## 3. Positive Sentences

### There Is

Use **there is** with singular countable nouns and uncountable nouns.

Structures:

- There is + a/an + singular countable noun.
- There is + some + uncountable noun.

Examples:

- There is a computer in my room.
- There is an apple in the bag.
- There is some water in the bottle.
- There is milk in the refrigerator.
- There is a new student in our class.

### There Are

Use **there are** with plural countable nouns.

Structure:

**There are + plural noun**

Examples:

- There are four chairs in the kitchen.
- There are ten students in the classroom.
- There are two windows in my bedroom.
- There are some books on the desk.

## 4. Negative Sentences

To make negative sentences, add **not** after is or are.

| Positive | Negative |
|---|---|
| There is a car. | There isn't a car. |
| There is some milk. | There isn't any milk. |
| There are two books. | There aren't two books. |
| There are some students. | There aren't any students. |

Contractions:

- There is not → There isn't
- There are not → There aren't

Examples:

- There isn't a TV in my bedroom.
- There isn't any coffee in the kitchen.
- There aren't any people in the park.
- There aren't many restaurants in this area.

## 5. Questions

To make questions, put **is** or **are** before there.

### Questions with Is There

Structure:

**Is there + a/an + singular noun?**

Examples:

- Is there a bank near here?
- Is there an airport in this city?
- Is there any water in the bottle?
- Is there a bathroom in this building?

### Questions with Are There

Structure:

**Are there + any + plural noun?**

Examples:

- Are there any students in the classroom?
- Are there any restaurants near your house?
- Are there two bedrooms in this apartment?
- Are there any parks in your neighborhood?

## 6. Short Answers

| Question | Positive | Negative |
|---|---|---|
| Is there a book? | Yes, there is. | No, there isn't. |
| Is there any milk? | Yes, there is. | No, there isn't. |
| Are there any chairs? | Yes, there are. | No, there aren't. |
| Are there any students? | Yes, there are. | No, there aren't. |

Important: In short answers, we normally do not repeat the noun.

Correct:

- Yes, there is.
- No, there aren't.

Incorrect:

- Yes, there is a book.
- No, there aren't students.

The longer answers are grammatically possible in other contexts, but the short forms are the standard answers to yes/no questions.

## 7. Using A, An, Some, and Any

We commonly use these words with there is and there are.

| Word | Common use | Example |
|---|---|---|
| a | Singular countable noun | There is a chair. |
| an | Singular countable noun beginning with a vowel sound | There is an egg. |
| some | Positive sentences | There are some books. |
| any | Negative sentences and questions | Are there any books? |

Examples:

- There is a dog in the garden.
- There is an orange on the table.
- There are some apples in the refrigerator.
- There isn't any sugar in the kitchen.
- Are there any supermarkets nearby?

## 8. There Is with Uncountable Nouns

Uncountable nouns use **there is**, not there are.

Examples:

- There is some rice in the kitchen.
- There is a little water in the glass.
- There is some information in this document.
- There isn't any furniture in the room.

Incorrect:

- There are some water.
- There are many furniture.

Correct:

- There is some water.
- There is some furniture.

## 9. Describing Places

We often use there is and there are to describe rooms, homes, cities, and neighborhoods.

### Example: My Bedroom

There is a bed in my bedroom. There is a desk next to the window. There are two chairs near the desk. There are some books on the shelf. There isn't a television in my bedroom.

### Example: My Neighborhood

There is a supermarket near my apartment. There are two restaurants on my street. There is a small park across from the supermarket. There aren't any large shopping malls nearby.

## 10. Common Mistakes

| Incorrect | Correct |
|---|---|
| There are a book on the table. | There is a book on the table. |
| There is three students. | There are three students. |
| There are some water. | There is some water. |
| Is there any restaurants? | Are there any restaurants? |
| There isn't some milk. | There isn't any milk. |
| Are there a bank nearby? | Is there a bank nearby? |

Remember:

- Use there is for singular and uncountable nouns.
- Use there are for plural countable nouns.
- Use is there in singular and uncountable questions.
- Use are there in plural questions.

## 11. American English Notes

In everyday American English:

- "There's" is a common contraction of "there is."
- "There are" is commonly used in full form, especially in careful speech.
- "There's a coffee shop near here" is a natural everyday sentence.
- In informal speech, some people use "there's" before plural nouns, but standard written English uses "there are."

Examples:

- There's a grocery store on this street.
- There are two gas stations near my house.
- Is there a restroom nearby?

## 14. Chapter Summary

- Use there is with singular countable nouns and uncountable nouns.
- Use there are with plural countable nouns.
- Add not to make negative sentences.
- Put is or are before there to make questions.

- Use some in many positive sentences.
- Use any in many negative sentences and questions.
- Use there is and there are to describe places and situations.
