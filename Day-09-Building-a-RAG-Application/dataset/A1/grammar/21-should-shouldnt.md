# Chapter 21: Modal Verb — Should and Shouldn't

## 1. Learning Objectives

By the end of this chapter, you will be able to:

- Give advice and suggestions using should.
- Say that something is a good or bad idea.
- Make positive and negative sentences.
- Ask questions with should.
- Use should in everyday situations.

## 2. What Is Should?

**Should** is a modal verb. We use it to give advice, make suggestions, and express what we think is the right or best thing to do.

Examples:

- You should study every day.
- She should drink more water.
- We should help our friends.
- He should get more sleep.

These sentences express advice, not an absolute rule or command.

## 3. Positive Sentences

### Structure

**Subject + should + base verb + complement**

| Subject | Example |
|---|---|
| I | I should exercise more. |
| You | You should study English. |
| He | He should see a doctor. |
| She | She should get some rest. |
| It | It should work. |
| We | We should leave early. |
| They | They should practice more. |

Important: Use the base form of the verb after should.

Correct:
- She should study.
- They should go.
- He should work.

Incorrect:
- She should studies.
- They should to go.
- He should worked.

## 4. Negative Sentences

Use **should not** or **shouldn't** to say that something is not a good idea.

### Structure

**Subject + should not + base verb + complement**

Examples:

- You should not smoke.
- He should not drive so fast.
- They should not be late.
- We should not waste time.

### Contraction

**Should not = Shouldn't**

Examples:

- You shouldn't eat too much candy.
- She shouldn't stay up late.
- We shouldn't ignore the problem.
- They shouldn't spend too much money.

## 5. Yes/No Questions

Put **should** before the subject.

### Structure

**Should + subject + base verb + complement?**

Examples:

- Should I call him?
- Should we leave now?
- Should she take this medicine?
- Should they wait here?

### Short Answers

| Question | Positive Answer | Negative Answer |
|---|---|---|
| Should I call? | Yes, you should. | No, you shouldn't. |
| Should we wait? | Yes, you should. | No, you shouldn't. |
| Should she go? | Yes, she should. | No, she shouldn't. |
| Should they stay? | Yes, they should. | No, they shouldn't. |

## 6. Wh- Questions

Put a question word before should.

### Structure

**Question word + should + subject + base verb?**

Examples:

| Question Word | Example |
|---|---|
| What | What should I do? |
| Where | Where should we go? |
| When | When should I call you? |
| Why | Why should he apologize? |
| How | How should I start? |
| Who | Who should we invite? |

More examples:

- What should I study?
- Where should they wait?
- When should we leave?
- How should she prepare?

## 7. Common Uses of Should

### Use 1: Giving Advice

Examples:

- You should practice English every day.
- You should get enough sleep.
- He should talk to his teacher.
- She should save some money.

### Use 2: Making Suggestions

Examples:

- We should watch a movie.
- We should try that restaurant.
- They should visit the museum.
- You should read this book.

### Use 3: Expressing the Right Thing to Do

Examples:

- People should respect each other.
- Students should do their homework.
- Drivers should follow traffic rules.
- Everyone should protect the environment.

### Use 4: Asking for Advice

Examples:

- What should I wear?
- Should I buy this laptop?
- Where should we meet?
- Should I learn Python or Go first?

## 8. Should vs. Must

Both words express obligation or recommendation, but they have different strengths.

| Should | Must |
|---|---|
| Advice or recommendation | Strong obligation or necessity |
| You should exercise. | You must wear a seat belt. |
| You should study more. | You must show your ID. |

Examples:

- You should drink more water. (Advice)
- You must stop at a red light. (Strong requirement)

## 9. Should vs. Shouldn't

| Should | Shouldn't |
|---|---|
| You should eat healthy food. | You shouldn't eat too much junk food. |
| He should study more. | He shouldn't waste time. |
| We should leave early. | We shouldn't arrive late. |

Remember: Shouldn't means that something is not recommended. It does not always mean that something is forbidden.

## 10. Common Mistakes

| Incorrect | Correct |
|---|---|
| You should to study. | You should study. |
| She should studies. | She should study. |
| He shouldn't goes. | He shouldn't go. |
| Should I to call him? | Should I call him? |
| Do I should go? | Should I go? |
| They should went home. | They should go home. |

## 11. American English Notes

These examples use standard American English.

- "You should get some rest" is a natural way to give advice.
- "You should check it out" is a common informal suggestion.
- "You shouldn't worry about it" is a common reassuring expression.
- "What should I do?" is a very common everyday question.

Examples:

- You should check out that new restaurant.
- We should grab some coffee.
- You shouldn't worry too much.
- I think you should take a break.

## 14. Chapter Summary

In this chapter, you learned:

- Use should to give advice and make suggestions.
- Use shouldn't to say that something is not recommended.
- Use should + base verb.
- Put should before the subject to make questions.
- Put question words before should for Wh-questions.
- Should expresses advice, while must expresses a stronger obligation.

### Key Structures

| Sentence Type | Structure |
|---|---|
| Positive | Subject + should + base verb |
| Negative | Subject + shouldn't + base verb |
| Yes/No Question | Should + subject + base verb? |
| Wh-Question | Question word + should + subject + base verb? |
