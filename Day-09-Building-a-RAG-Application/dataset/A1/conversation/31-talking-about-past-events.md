# Chapter 31: Talking About Travel

## Learning Objectives

By the end of this chapter, you will be able to:

- Talk about places you want to visit.
- Ask someone about travel plans.
- Describe simple travel activities.
- Talk about transportation and destinations.

## 1. Key Expressions

| Expression | Example |
|---|---|
| Do you like traveling? | Do you like traveling? |
| Where do you want to go? | Where do you want to go? |
| I want to visit ... | I want to visit Japan. |
| Have a safe trip! | Have a safe trip! |
| How do you travel? | How do you travel to work? |
| By plane | I travel by plane. |
| I travel with ... | I travel with my family. |
| How was your trip? | How was your trip? |

## 2. Example Conversations

### Conversation 1: Favorite Places

**Anna:** Do you like traveling?

**David:** Yes, I do.

**Anna:** Where do you want to go?

**David:** I want to visit Italy.

**Anna:** That sounds wonderful!

### Conversation 2: Travel Plans

**Lisa:** Are you going to travel this summer?

**Mark:** Yes. I'm going to visit Spain.

**Lisa:** Who are you going with?

**Mark:** I'm going with my family.

### Conversation 3: Talking About a Trip

**Emma:** How was your trip?

**John:** It was great!

**Emma:** Where did you go?

**John:** I went to Paris.

**Emma:** Did you like it?

**John:** Yes, it was beautiful.

## 3. Useful Vocabulary

| Word | Meaning |
|---|---|
| travel | Go from one place to another |
| trip | A journey to a place |
| destination | The place you want to go |
| tourist | A person who visits a place |
| passport | An official travel document |
| suitcase | A bag for clothes when traveling |
| ticket | A document that allows you to travel |
| airport | A place where planes arrive and leave |
| train | A vehicle that travels on railway tracks |
| plane | An aircraft |
| map | A picture that shows places |
| journey | Travel from one place to another |
