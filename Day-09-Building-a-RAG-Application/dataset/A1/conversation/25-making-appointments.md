# Chapter 25: Accepting and Refusing Invitations

## Learning Objectives

By the end of this chapter, you will be able to:

- Accept an invitation politely.
- Refuse an invitation politely.
- Give a simple reason when you cannot come.
- Suggest another time.

## 1. Key Expressions

| Expression | Example |
|---|---|
| Yes, I'd love to. | Yes, I'd love to come. |
| Sure! | Sure! See you there. |
| That sounds great. | That sounds great! |
| Thank you for inviting me. | Thank you for inviting me. |
| Sorry, I can't. | Sorry, I can't come. |
| I'm busy. | I'm busy tonight. |
| Maybe next time. | Maybe next time! |
| How about tomorrow? | How about tomorrow instead? |

## 2. Example Conversations

### Conversation 1: Accepting an Invitation

**Alex:** Would you like to have lunch with me?

**Maria:** Yes, I'd love to!

**Alex:** Great! Let's meet at noon.

**Maria:** See you then.

### Conversation 2: Refusing Politely

**John:** Do you want to go shopping?

**Lisa:** I'm sorry, I can't. I'm busy today.

**John:** That's okay.

**Lisa:** Maybe tomorrow?

**John:** Sure!

### Conversation 3: Suggesting Another Time

**Tom:** Can you come to my house tonight?

**Sara:** Sorry, I can't tonight.

**Tom:** No problem.

**Sara:** How about Saturday?

**Tom:** Saturday is great!

## 3. Useful Vocabulary

| Word | Meaning |
|---|---|
| accept | Say yes to an invitation |
| refuse | Say no to an invitation |
| sorry | A polite word when something is wrong |
| busy | Having something to do |
| available | Free to do something |
| maybe | Perhaps |
| instead | In place of something else |
| invitation | A request to join an event |
| reason | Why something happens |
| tomorrow | The day after today |
| next time | A future occasion |
| noon | 12:00 p.m. |
