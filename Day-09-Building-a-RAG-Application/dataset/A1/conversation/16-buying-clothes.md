# Chapter 16: Buying Clothes

## Learning Objectives

- Name common clothing items.
- Ask about sizes and colors.
- Try on clothes.
- Talk about fit and price.

## Key Expressions

| Expression | Example |
|---|---|
| I'm looking for a shirt. | I'm looking for a blue shirt. |
| What size are you? | I'm a medium. |
| Do you have a larger size? | Do you have a larger size? |
| Can I try it on? | Can I try this jacket on? |
| Where is the fitting room? | Where is the fitting room? |
| It fits well. | This shirt fits well. |
| It's too small. | These pants are too small. |
| It looks great! | That dress looks great! |

## Conversation 1: Buying a Shirt

**Assistant:** Hello! Can I help you?

**Customer:** Yes, I'm looking for a white shirt.

**Assistant:** What size do you need?

**Customer:** Medium, please.

**Assistant:** Here is a white shirt in medium.

**Customer:** Can I try it on?

**Assistant:** Of course. The fitting room is over there.

**Customer:** Thank you. It fits perfectly!

## Conversation 2: Choosing a Jacket

**Mia:** What do you think of this jacket?

**Emma:** I like it. The color is beautiful.

**Mia:** Do you think it looks good on me?

**Emma:** Yes! It looks great.

**Mia:** It's a little expensive, though.

**Emma:** Maybe you can find a cheaper one.

## Conversation 3: Asking for Another Size

**Customer:** Excuse me. These pants are too small.

**Assistant:** What size do you need?

**Customer:** Do you have a large size?

**Assistant:** Yes. Here you are.

**Customer:** Thank you. These fit much better.

## Useful Vocabulary

| Word | Meaning |
|---|---|
| Shirt | Clothing for the upper body |
| Pants | Clothing for the legs |
| Jacket | Clothing worn over a shirt |
| Dress | A one-piece item of clothing |
| Shoes | Clothing worn on the feet |
| Size | How big or small something is |
| Small | A small clothing size |
| Medium | A middle clothing size |
| Large | A big clothing size |
| Fitting room | A room where customers try on clothes |
| Fit | To be the right size |
| Comfortable | Making you feel relaxed |
