# Chapter 19: The Home and Furniture

## Learning Objectives

By the end of this chapter, you can:
- Name common types of homes.
- Identify basic furniture.
- Describe your home using simple sentences.

## 1. Types of Homes

| Word | Meaning |
|---|---|
| house | A building where people live |
| apartment | A home inside a larger building |
| home | The place where someone lives |
| building | A structure with walls and a roof |
| cottage | A small house, often in the countryside |
| farmhouse | A house on a farm |
| room | A part of a building |
| floor | One level of a building |
| roof | The top covering of a building |
| wall | A vertical part of a room or building |

## 2. Furniture

| Word | Meaning |
|---|---|
| bed | Furniture used for sleeping |
| sofa | A long, comfortable seat |
| chair | Furniture for one person to sit on |
| table | Furniture with a flat top |
| desk | A table used for working or studying |
| wardrobe | Furniture used for storing clothes |
| closet | A small space or cupboard for storing things |
| bookshelf | Furniture used for keeping books |
| cabinet | Furniture used for storage |
| drawer | A sliding storage compartment |
| mirror | Something that shows your reflection |
| lamp | Something that gives light |

## 3. Home Objects

| Word | Meaning |
|---|---|
| pillow | A soft object for your head in bed |
| blanket | A warm covering for a bed |
| carpet | A floor covering |
| curtain | Material that covers a window |
| clock | Something that shows the time |
| picture | An image on a wall |
| key | A small object used to open a lock |
| door | An entrance to a room or building |
| window | An opening in a wall that lets in light |

## 4. Example Sentences

- I live in a small apartment.
- There is a sofa in the living room.
- My bedroom has a large bed.
- The books are on the bookshelf.
- We have a table and four chairs.
- There are two windows in my room.
- My keys are on the desk.

## 5. Useful Expressions

- I live in a house.
- My home is small.
- There are three rooms.
- The sofa is next to the window.
- The lamp is on the table.
- My bedroom is upstairs.

## 6. Short Dialogue

**Alex:** Do you live in a house or an apartment?

**Sara:** I live in an apartment.

**Alex:** How many rooms does it have?

**Sara:** It has two bedrooms, a kitchen, and a living room.

**Alex:** Is it big?

**Sara:** No, it is small, but it is comfortable.

   - c) cabinet

2. You keep books on a ______.

   - b) bookshelf
   - c) pillow

3. You look at yourself in a ______.
   - a) mirror
   - b) blanket
   - c) drawer

4. You sit on a ______.
   - a) chair
   - b) lamp
   - c) window

### Exercise C: True or False

2. A blanket is used to cover a window.
3. A wardrobe is used to store clothes.
4. A roof is usually at the top of a building.
