# Chapter 03: Colors and Shapes

## 1. Learning Objectives

- Identify common colors.
- Name basic shapes.
- Describe objects using colors and shapes.
- Ask and answer questions about colors.

## 2. Basic Colors

| Color | Example |
|---|---|
| red | The apple is red. |
| blue | The sky is blue. |
| yellow | The sun is yellow. |
| green | The grass is green. |
| black | My bag is black. |
| white | The paper is white. |
| orange | The orange is orange. |
| purple | Her dress is purple. |
| pink | The flower is pink. |
| brown | The table is brown. |
| gray | The cat is gray. |

## 3. Light and Dark Colors

We can use "light" and "dark" to describe colors.

| Expression | Example |
|---|---|
| light blue | My shirt is light blue. |
| dark blue | His car is dark blue. |
| light green | The wall is light green. |
| dark green | The tree is dark green. |
| light pink | Her bag is light pink. |

## 4. Basic Shapes

| Shape | Example |
|---|---|
| circle | The clock is a circle. |
| square | The window is square. |
| triangle | The sign is a triangle. |
| rectangle | The door is a rectangle. |
| oval | The egg is an oval. |
| star | The star has five points. |
| heart | The card has a heart. |
| diamond | The shape looks like a diamond. |

## 5. Describing Objects

We can use a color and a shape together.

Examples:

- It is a red circle.
- I have a blue square.
- The sign is a yellow triangle.
- This is a white rectangle.
- She has a pink heart-shaped bag.

## 6. Useful Questions

| Question | Answer |
|---|---|
| What color is it? | It is red. |
| What color is your car? | It is black. |
| What shape is it? | It is a circle. |
| What color do you like? | I like blue. |
| Is it green? | Yes, it is. |
| Is it a square? | No, it isn't. |

## 7. Examples in Context

1. My favorite color is blue.
2. The ball is round and red.
3. The classroom door is brown.
4. I have a yellow notebook.
5. The clock is a white circle.
6. The traffic sign is a red triangle.

## 8. Short Conversation

**Lisa:** What is your favorite color?

**Ben:** My favorite color is green.

**Lisa:** What color is your bag?

**Ben:** It is black.

**Lisa:** What shape is your clock?

**Ben:** It is a circle.

## 9. Exercises

### Exercise A: Multiple Choice

1. What color is the sky on a clear day?
   - a) Blue
   - b) Black
   - c) Brown

2. Which shape has three sides?
   - a) Circle
   - b) Triangle
   - c) Square

3. What is the opposite of black?
   - a) White
   - b) Green
   - c) Pink

4. Which shape has four equal sides?
   - a) Oval
   - b) Square
   - c) Circle

5. What color is a common ripe banana?
   - a) Purple
   - b) Yellow
   - c) Gray

### Exercise B: True or False

1. A circle has no corners.
2. A triangle has four sides.
3. Grass is usually green.
4. A rectangle has four sides.
5. Pink is a shape.

### Exercise C: Complete the Sentences

Use: **blue - square - red - circle - green**

1. The sky is ______.
2. A window can be a ______.
3. A stop sign is usually ______.
4. A clock can be a ______.
5. Grass is ______.

### Exercise D: Short Answers

1. What is your favorite color?
2. What color is your phone?
3. What shape is your computer screen?
4. Do you like purple?
